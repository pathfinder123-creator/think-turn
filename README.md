# ThinkTurn

Look through a new lens

## Publish on GitHub Pages

Unzip the package and upload its contents to the folder that GitHub Pages serves. Keep index.html, manifest.webmanifest, sw.js, and the icons folder together, with the same names. Open the published HTTPS address to use the app.

## Install on a phone

- On iPhone, open the published address in Safari. Choose Share, then Add to Home Screen. Turn on Open as Web App if offered and tap Add.
- On Android, open the published address in Chrome. Use Install on your device on the page or the Install app option in the browser menu.

Give the app a moment on its first online visit to prepare offline access. To check offline access, close the app after that visit, switch to airplane mode, and reopen it. Assessment answers and notes stay in the open session. Download a reflection before closing the app if you want to keep a copy.
